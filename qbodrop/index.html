Questions

What people ask before they convert a first statement.

Is my statement uploaded anywhere?

No. The file is read and converted by your browser. You can load the page, switch off your internet and it still converts.

Which QuickBooks versions take the file?

QuickBooks Online and QuickBooks Desktop both import .qbo files through Banking, Upload from file. Xero, Sage, Wave and other software that reads OFX take the .ofx file.

What does "Bank in QuickBooks" mean?

QuickBooks Desktop only accepts a .qbo file that names a bank it knows. The default works for any bank's transactions. If you know your own bank's ID you can enter it.

Will importing twice create duplicates?

No. Each transaction gets an ID built from its date, amount and description, so QuickBooks recognises one it has already imported.

My bank has separate debit and credit columns. Does that work?

Yes. Qbodrop reads one signed amount column or separate money in and money out columns, and brackets, trailing minus signs, DR and CR marks, and European decimals.

Can it read a PDF statement?

Not yet. Download the CSV or Excel export from online banking instead; nearly every bank offers one next to the PDF.
